# SidecarZero Go SDK (`sdks/go`)

[← 09 — Pure-Go SDK Spec](../../docs/components/09-sdk-go.md) · [06 — Shared SDK Contract](../../docs/components/06-sdk-contract.md)

Pure-Go client (`CGO_ENABLED=0`, Go 1.24+) implementing the SidecarZero SDK contract using only the Go standard library (`net.UnixConn`, `syscall`, `sync/atomic`, `unsafe`) with zero third-party dependencies.

```go
import sidecarzero "github.com/PromptCultivator/sidecar-zero/sdks/go"

client, err := sidecarzero.New(
    sidecarzero.UnixPath("/run/sidecarzero/scz.sock"),
    sidecarzero.NewDenseF32Score(256),                 // features: float32[1, 256] → score
    sidecarzero.ThresholdFallback(17, 0.8, 0.9, 0.1),  // mandatory; nil is rejected at construction
)
out := client.Infer(features, 2*time.Millisecond)      // zero heap allocations; out.Source indicates Model or Fallback
```

## Directory Layout

| Path | Description |
|---|---|
| `client.go` | `Client[In, Out]`, `New`, `Infer`, `Session`, `Stats`, `Close`, `AwaitBound`; sampled latency timing and `WithOnFallback` hook; normative call algorithm ([06 — SDK Contract §4](../../docs/components/06-sdk-contract.md#4-the-call-algorithm-normative)), overload circuit breaker, and late-wake tracking |
| `core.go` | Shared client state: atomic `ArenaSnapshot` pointer, 1,024-entry `CallerEntry` table with in-call markers, schema binding, arena retirement, and monitor goroutine |
| `conn_linux.go` | Background session goroutine: `SOCK_SEQPACKET` handshake (`SCM_RIGHTS` with `MSG_CMSG_CLOEXEC`), seal verification, read-only control mapping, directory validation, page pre-faulting, `READY`, and jittered reconnect |
| `conn_other.go` | Non-Linux stub: constructs cleanly and returns the caller's fallback with `FallbackReasonNotConnected` |
| `clock.go` | Calibrated monotonic clock (`offset + time.Since(base)`) verified every 250 ms against `CLOCK_MONOTONIC` |
| `codec.go`, `reason.go` | `Codec[In, Out]`, `SlotWriter`/`SlotReader`, prebuilt codecs (`DenseF32Score`, `DenseF32Batch`, `Raw`), `Fingerprint`, `FallbackReason`, and `Outcome[Out]` |
| `metrics.go`, `export.go` | 1,024 stack-striped sampling counters, 16-shard atomic histograms, `MetricsSink`, `Label`, `Export`, and `PrometheusText` |
| `fallbacks.go` | Reference fallbacks (`ConstantFallback`, `ThresholdFallback`, `LinearFallback`) and `MeasureFallback` |
| `inprocess.go` | `NewInProcess`: in-process test double exercising the real shared-memory call path over process-local memory |
| `internal/abi/abi.go` | Generated by `scz-abi-gen` (`crates/scz-abi-gen/src/go.rs`): ABI constants and typed atomic accessor methods on `abi.Seg` |
| `internal/abi/seg*.go` | `abi.Seg` atomic load/store/CAS primitives, bounded payload copy helpers, `futex`, and `mmap` |
| `internal/shm/` | Shared-memory protocol implementation (directory, ring enqueue, slot transitions, Arrow IPC registry parser, model seqlock, and XXH3-64) |
| `cmd/scz-agent-go/` | Conformance agent (`scz-agent-go`) implementing conformance protocol v2 |

## Building and Testing

Inside the development container (`scripts/dev`):

```bash
scripts/dev bash -c 'sdks/go/build.sh && sdks/go/test.sh'
scripts/dev bash -c 'sdks/go/build.sh && target/release/scz-conformance --bins=target/release \
    --crash-bins=target/crash/release --agent=target/sdk/go/scz-agent-go \
    --crash-agent=target/sdk/go/crash/scz-agent-go \
    conformance/scenarios conformance/scenarios/crash'
```

`build.sh` cross-compiles the package for Linux, macOS, and Windows and builds both the standard conformance agent (`target/sdk/go/scz-agent-go`) and the crash-point-instrumented agent (`target/sdk/go/crash/scz-agent-go`).

`test.sh` executes:

1. `gofmt` and `go vet` (Linux and macOS targets)
2. Full unit, golden-vector, and metrics test suite under the Go race detector (`go test -race ./...`)
3. Compiler escape analysis verification (`-gcflags=-m`) confirming zero heap escapes on the `Infer` and `Session.Infer` call paths
4. AST/package boundary lint (`lint_test.go`) verifying that `unsafe` and `syscall.Mmap` are confined to `internal/abi` and `internal/sys` and that all shared-memory accesses go through generated `abi.Seg` methods
5. Zero-allocation gate verifying `0` allocations (`runtime.MemStats.Mallocs` delta) across 1,000,000 calls for every call outcome (spinning model hit, parked model hit, admission fallback, `NOT_CONNECTED`, `OVERLOADED` shed, deadline abandon, polling wait beyond the parked-caller cap, and `Session.Infer`)
