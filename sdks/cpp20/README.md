# SidecarZero C++20 SDK (`sdks/cpp20`)

[← 08 — C++20 Header-Only SDK Spec](../../docs/components/08-sdk-cpp20.md) · [06 — Shared SDK Contract](../../docs/components/06-sdk-contract.md)

Header-only C++20 client implementing the SidecarZero SDK contract with zero external dependencies beyond `libc`, `libstdc++`, and `pthread`.

```cpp
#include <scz/sidecarzero.hpp>

scz::Client client{
    scz::Endpoint::path("/run/sidecarzero/scz.sock"),
    scz::codecs::DenseF32ToScore<256>{},
    [](const std::array<float, 256>& x, scz::FallbackReason) noexcept {
        return x[17] > 0.8f ? 0.9f : 0.1f;
    }};

auto r = client.infer(features, std::chrono::milliseconds(2));   // noexcept; always returns an Outcome
std::string body = client.prometheus_text();                       // Prometheus text exposition
```

## Directory Layout

| Path | Description |
|---|---|
| `include/scz/sidecarzero.hpp` | Top-level umbrella header |
| `include/scz/abi.hpp` | Generated by `scz-abi-gen` (`crates/scz-abi-gen/src/cpp.rs`): constants, enums, bitfields, region offsets with `static_assert`s, and `std::atomic_ref` accessors with memory ordering fixed by `abi/scz_abi.toml` |
| `include/scz/detail/platform.hpp` | `CLOCK_MONOTONIC`, architecture spin hint (`_mm_pause` / `yield`), shared `futex`, `gettid`, `tgkill` thread liveness check, and kernel constants |
| `include/scz/detail/shared.hpp` | `fetch_once` single-load helper, slot word and gate word bitfield manipulation |
| `include/scz/detail/hash.hpp` | Dependency-free XXH3-64 (`seed = 0`) and CRC-32C implementations |
| `include/scz/detail/layout.hpp` | Arena directory parser and validator over the read-only control segment |
| `include/scz/detail/ring.hpp` | Bounded MPSC enqueue (`≤ 64` attempts), `RingWakeWord` protocol, RAII void-on-unwind scope guard, and crash points |
| `include/scz/detail/slot.hpp` | Bounded slot claim (`≤ 8` probes), `READY`, release, cancel, adaptive spin + futex wait, and `ABANDONED` transition (preserving `OWNER`) |
| `include/scz/detail/registry.hpp` | Schema fingerprint computation, `RegistryHeader`/`TemplateDesc` validation, model seqlock reader, and Arrow IPC frame stamping |
| `include/scz/detail/handshake.hpp` | UDS `SOCK_SEQPACKET` `HELLO` / `WELCOME` + `SCM_RIGHTS` (`MSG_CMSG_CLOEXEC`) / `READY` handshake |
| `include/scz/codec.hpp` | `SlotWriter`/`SlotReader`, `FrameWriter`/`FrameReader`, `OpaqueCodec` and `FrameCodec` C++20 concepts, and prebuilt codecs (`DenseF32ToScore<N>`, `DenseF32Batch<N>`, `RawBytes`) |
| `include/scz/fallback.hpp` | `FallbackReason`, `Outcome`, `FallbackPolicy` and `FallbackHook` C++20 concepts, `NoHook`, and reference fallbacks |
| `include/scz/metrics.hpp` | `kBucketsSeconds`, 16-shard lock-free histograms, `Histogram`, `Label`, `MetricsSink`, and `PrometheusText` |
| `include/scz/client.hpp` | `Client<Codec, Fallback, Hook>`, normative call algorithm, 1,024-entry `CallerEntry` table, `stats()`, `export_metrics()`, `prometheus_text()`, background reconnect thread, and `pthread_atfork` handler |
| `CMakeLists.txt`, `cmake/sidecarzeroConfig.cmake.in` | CMake `INTERFACE` package exporting `sidecarzero::sidecarzero` |
| `agent/agent.cpp` | Conformance agent (`scz-agent-cpp20`) implementing conformance protocol v2 |
| `tests/` | Unit tests, `alloc_gate.cpp` (global allocator interposition), concurrency stress suite (`test_stress.cpp`), compile-fail concept checks, `local_arena.hpp`, and `cmake-consumer` test project |

## Building and Testing

Inside the development container (`scripts/dev`):

```bash
scripts/dev bash -c 'sdks/cpp20/build.sh && sdks/cpp20/test.sh'
scripts/dev bash -c 'sdks/cpp20/build.sh && target/release/scz-conformance --bins=target/release \
    --crash-bins=target/crash/release --agent=target/sdk/cpp20/scz-agent-cpp20 \
    --crash-agent=target/sdk/cpp20/crash/scz-agent-cpp20 \
    conformance/scenarios conformance/scenarios/crash'
```

`test.sh` compiles and runs:

1. Compile-time concept rejection tests (`compile-fail`)
2. Header cleanliness checks (`-Wconversion -Wsign-conversion`, both with and without `-fno-exceptions -fno-rtti`)
3. Unit and metrics tests (standard, `-fno-exceptions -fno-rtti`, TSan, and ASan+UBSan)
4. Global-allocator zero-allocation gate (`tests/alloc_gate.cpp`) across all hot-path outcomes
5. Multi-threaded concurrency stress tests (standard, TSan, and ASan)
6. CMake `find_package(sidecarzero)` installation and consumer verification (`tests/cmake-consumer`)

## CMake Integration

```cmake
# Installed via: cmake -S sdks/cpp20 -B build && cmake --install build --prefix /opt/scz
find_package(sidecarzero 0.1 REQUIRED)
target_link_libraries(my_service PRIVATE sidecarzero::sidecarzero)

# Or vendored directly:
add_subdirectory(sdks/cpp20)
target_link_libraries(my_service PRIVATE sidecarzero::sidecarzero)
```
