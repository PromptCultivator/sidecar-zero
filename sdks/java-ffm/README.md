# SidecarZero Java FFM SDK (`sdks/java-ffm`)

[← 07 — Java 22+ FFM SDK Spec](../../docs/components/07-sdk-java-ffm.md) · [06 — Shared SDK Contract](../../docs/components/06-sdk-contract.md)

Pure-Java client built on the Foreign Function & Memory API (`java.lang.foreign`). Requires zero JNI, zero native shared libraries, and zero third-party dependencies.

```java
ScoreClient c = SidecarZero.connect("/run/sidecarzero/scz.sock")
        .score(256)                                   // features: float32[1, 256] -> score: float32[1, 1]
        .fallback((features, reason) -> 0.0f)         // mandatory: build() is reachable only through here
        .build();                                     // returns immediately; background thread connects
long o = c.scoreOutcome(features, 2_000_000);         // 2 ms budget; zero heap allocation
float s = ScoreOutcome.score(o);                      // ScoreOutcome.fromModel(o), .reason(o)
```

Run the JVM with `--enable-native-access=ALL-UNNAMED`. Off Linux (such as macOS and Windows development hosts), the client constructs without linking native symbols and every call returns the caller's fallback with `FallbackReason.NOT_CONNECTED`.

## Directory Layout

| Path | Description |
|---|---|
| `src/main/java/io/sidecarzero/` | Public API: `SidecarZero` (typestate builder: `EndpointStage` → `CodecStage` → `BuildStage`), `Client`/`Outcome` (generic), `ScoreClient`/`ScoreOutcome` and `BatchScoreClient` (primitive, zero-allocation), `DenseCodec`, `Codec` (`SlotWriter`/`SlotReader`/`FrameWriter`/`FrameReader`), `FallbackPolicy`, `FallbackReason`, `Options`, `Stats`, `Schema`/`Column`, `MetricsSink`/`PrometheusText`/`Histogram` |
| `src/main/java/io/sidecarzero/Engine.java` | Normative call algorithm ([06 — SDK Contract §4](../../docs/components/06-sdk-contract.md#4-the-call-algorithm-normative)), overload breaker, adaptive spin/futex/virtual-thread waits, background session lifecycle, and arena retirement |
| `src/main/java/io/sidecarzero/Session.java` | UDS `SOCK_SEQPACKET` handshake (`SCM_RIGHTS` with `MSG_CMSG_CLOEXEC`, `F_GET_SEALS`, segment sizing, `mmap`), model seqlock reader, and schema binding |
| `src/main/java/io/sidecarzero/internal/Abi.java` | Generated by `scz-abi-gen` (`crates/scz-abi-gen/src/java.rs`): ABI constants, bitfield helpers, and typed `VarHandle` accessors with memory ordering fixed by `abi/scz_abi.toml` |
| `src/main/java/io/sidecarzero/internal/` | `Native` (`Linker` downcalls), `Clock` (calibrated `System.nanoTime()`), `Directory`, `Registry`, `Xxh3` |
| `src/agent/java/io/sidecarzero/agent/Main.java` | Conformance agent (`scz-agent-java`) implementing conformance protocol v2 |
| `src/test/java/io/sidecarzero/` | `Tests` (unit and golden-vector tests), `MetricsTests`, `Stress` (multi-threaded concurrency stress suite), `AllocGate` (zero-allocation gate) |
| `build.sh`, `test.sh` | Builds `target/sdk/java-ffm/{sidecarzero.jar,scz-agent.jar,scz-agent-java}` and executes all test suites and allocation gates |

## Building and Testing

Inside the development container (`scripts/dev`):

```bash
scripts/dev bash -c 'sdks/java-ffm/build.sh && sdks/java-ffm/test.sh'
scripts/dev bash -c 'sdks/java-ffm/build.sh && target/release/scz-conformance --bins=target/release \
    --crash-bins=target/crash/release --agent=target/sdk/java-ffm/scz-agent-java \
    conformance/scenarios conformance/scenarios/crash'
```

Setting `SCZ_JAVA_DEBUG=1` logs background connection attempts and timings to `stderr`.

## Implementation Highlights

- **Generated Ordered Memory Access:** All shared-memory loads, stores, and CAS operations go exclusively through `io.sidecarzero.internal.Abi`. `const` and `relaxed` fields use `getOpaque`/`setOpaque`, `acqrel` fields use `getAcquire`/`setRelease` (with `*Volatile` accessors where sequentially consistent store-then-load ordering is required), and `cas` fields expose `compareAndSet` and `getAndAdd`.
- **Zero-Allocation Hot Path & Pre-Warming:** Caller state is stored in a fixed 1,024-entry claimed `Caller` array (avoiding `ThreadLocal` initial-call allocations). After its first connection attempt, the background thread pre-warms all ring/slot/wait methods (~400 iterations over process-local memory) and invokes each FFM downcall handle 300 times so HotSpot's 127-invocation lambda-form customization never occurs on a request thread. `AllocGate` verifies `0 B` allocated per call via `ThreadMXBean.getThreadAllocatedBytes`.
- **Virtual Threads:** Virtual threads spin up to `min(spin_ns, ceiling)` and enter the native `futex` wait only while fewer than `availableProcessors - 1` virtual threads are currently parked in `futex` across the JVM. Beyond that cap (or when `Options.virtualPolling(true)` is set), virtual threads unmount and poll via `LockSupport.parkNanos(2_000 → 200_000)`.
- **Striped Metrics & Prometheus Export:** `Options.sampleEvery(n)` (default `64`) tracks call counts across 1,024 cache-line-padded thread-ID stripes (`threadId & 1023`), ensuring `1/64` sampling even in virtual-thread-per-request servers without allocating per-thread state. `export(MetricsSink)` and `prometheusText()` emit all metrics in the exact schema and floating-point formatting specified in [06 — SDK Contract §8](../../docs/components/06-sdk-contract.md#8-metrics-and-observability).
